# 진행자 안내서

한 회차의 **경매를 준비하고 진행하는 진행자**를 위한 안내서입니다.
신청 관리는 [운영자 안내서](운영자-안내서.md)를 먼저 보세요.

- 진행자 = 그 회차를 만든 운영자 (콘솔에서 다른 운영자에게 넘길 수 있음)
- 제작자와 **모든 회차 진행 권한**을 받은 운영자(예: 요한님)도 모든 회차에서 진행자와 같은 일을 할 수 있습니다.
- 진행자는 **운영자 초대 링크**를 보내고 들어온 요청을 **승인·거절**할 수 있습니다(콘솔 왼쪽 **운영자 관리 · 초대**). 운영자 빼기와 링크 바꾸기는 제작자만 합니다.

---

## 1. 한눈에 보는 순서

1. **신청 마감** (운영자 콘솔 → 일정 · 신청 마감 → 지금 마감)
2. **경매 준비** (운영자 콘솔 → 경매 준비 탭)
   1. 팀장 정하기 → 5명 단위로 맞추고 경매 티어 나누기 → **경매 선수 채우기**
   2. 경매 설정 확인
   3. 팀장 링크 보내기
   4. 경매 순서 정하기 (또는 진행자 화면에서 방송용 추첨)
3. **방송 화면**을 OBS에 띄우기
4. **진행자 화면**에서 경매 진행
5. **결과** 발표 → 엑셀·이미지 저장

---

## 2. 경매 규칙 (기본값)

| 항목 | 기본값 | 설명 |
|---|---|---|
| 시작 포인트 | 1000P | 팀마다 (핸디캡만큼 깎고 시작) |
| 입찰 단위 | 5P | 팀장 폰의 빠른 버튼은 +5, +10 |
| 팀 인원 | 5명 | 팀장 포함. 경매 티어를 쓰면 반드시 5명 |
| 빈자리 몫 | 5P | 빈자리 1칸마다 남겨야 하는 포인트 |
| 처음 시간 | 15초 | 선수 한 명당 |
| 입찰하면 | +5초 | 최대 15초까지 (남은 시간이 15초를 넘지 않음) |
| 유찰 | 2번 | 두 번 유찰되면 빈자리 팀에 무작위 배정 |

경매 티어(A·B·C·D)
- 팀장은 따로이고, 팀마다 **A·B·C·D 선수를 한 명씩** 가져갑니다.
- 이미 그 티어 선수가 있는 팀은 입찰할 수 없습니다(서버가 막음).
- 그 티어를 받을 수 있는 팀이 **한 팀뿐**이면 경매 없이 그 팀에 **0P로 자동 배정**합니다.
- 경매 순서는 티어와 상관없이 전부 섞습니다.

티어 점수
- 신청자가 적은 최고·현재 티어를 점수표로 바꿔 섞은 값입니다(기본은 반반).
- **언랭**: 최고 티어가 언랭이면 0점, 현재 티어만 언랭이면 최고 티어 점수만 씁니다.
- 경매 준비 → 경매 설정에서 점수표와 섞는 비율을 바꿀 수 있습니다.

## 3. 경매 준비 (운영자 콘솔 → 회차 → 경매 준비 탭)

### ① 명단 · 팀장 · 핸디캡 → 경매 선수 채우기
1. 표에서 팀장 줄의 **★**를 누릅니다. 누른 순서가 팀 순서입니다(★ 1팀, ★ 2팀 …).
2. 팀장 줄의 **핸디캡** 칸에 깎을 포인트를 적습니다(잘하는 팀장일수록 크게).
3. **5명 단위로 맞추고 경매 티어 A~D 나누기**를 누릅니다.
   - 신청 인원 ÷ 5 = 팀 수입니다. 남는 인원은 **늦게 신청한 사람부터 대기**로 빠집니다.
   - 팀장을 뺀 사람들을 티어 점수가 높은 순으로 팀 수만큼씩 A, B, C, D로 나눕니다.
   - 대기 인원에게도 점수에 맞는 티어가 붙습니다(대타용).
   - 팀장 수가 팀 수와 다르면 버튼이 알려 줍니다. 팀장(★) 수를 먼저 맞추세요.
4. 필요하면 표의 **경매 티어** 칸에서 한 명씩 바꿉니다. 위쪽에 "A 6 B 6 C 6 D 6"처럼 인원이 보이고, 맞지 않으면 빨간 글씨로 알려 줍니다.
5. **이 명단으로 경매 선수 채우기**를 누릅니다.

대타 넣기(경매 전)
- 못 오는 사람 줄의 **포함** 체크를 끄고, 같은 티어의 대기 인원 체크를 켠 뒤 **이 명단으로 경매 선수 채우기**를 다시 누릅니다.

### ② 경매 설정
- 시작 포인트, 입찰 단위, 팀 인원, 빈자리 몫, 팀별 핸디캡, 최고 티어 비율, 티어 점수표.
- **시간**: 선수마다 처음 시간, 입찰할 때마다 늘어나는 시간, 최대 시간(기본 15초·+5초·최대 15초). 처음 시간은 최대 시간보다 길 수 없습니다.
- **설정 저장**을 누르면 팀장 화면에 바로 반영됩니다.
- 포인트 규칙과 핸디캡은 경매 시작 전에만, 시간·점수표·비율은 언제든 바꿀 수 있습니다(시간은 다음 선수부터 적용).

### ③ 팀장 링크
- ①에서 경매 선수를 채우면 **팀장 수만큼** 링크가 생기고, 각 링크 이름은 **팀장 닉네임**입니다(예: 팀장 새벽고양이). 운영자 콘솔 **링크** 탭에도 같은 링크가 있습니다.
- 채우기 전에는 어느 링크가 어느 팀인지 정해지지 않아서 보여 주지 않습니다.
- **팀장 링크 한 번에 복사** → "팀장 닉네임: 링크" 줄로 복사됩니다.
- **각 팀장에게 자기 팀 링크만** 개인 메시지로 보내세요. 링크를 가진 사람은 그 팀으로 입찰할 수 있습니다.

### ④ 경매 순서
- **무작위로 섞기** 또는 ▲▼로 직접 정하고 **이 순서로 확정**.
- 방송에서 추첨 장면을 보여 주고 싶으면 여기서 확정하지 말고, 진행자 화면의 **방송용 순서 추첨**을 쓰세요.

## 4. 방송 화면 (OBS)

1. 운영자 콘솔 → **링크** 탭(또는 경매 준비 탭의 **방송 화면 열기**)에서 **방송 화면 (OBS)** 링크를 복사합니다.
2. OBS → 소스 추가(+) → **브라우저** → URL에 붙여 넣기 → 너비 **1920**, 높이 **1080**.
3. 방송 화면에는 버튼이 없습니다. 준비 중에는 "선수 경매 곧 시작"과 팀장들이 보이고, 경매가 시작되면 자동으로 바뀝니다.
4. 효과음이 OBS 소리로 나갑니다. 소리를 끄려면 링크 끝에 `&sound=0`을 붙이세요.
5. 결과 발표를 다시 틀려면 OBS에서 소스 우클릭 → **상호작용** → 키보드 **R**.

방송 화면에는 디스코드 이름과 채팅이 나오지 않습니다. 이 링크는 보기 전용이라 새어 나가도 경매를 조작할 수 없습니다.

## 5. 진행자 화면 사용법

진행자 화면은 콘솔 경매 준비 탭의 **진행자 화면 열기**로 엽니다. 이 링크는 경매를 조작하는 열쇠이니 **다른 사람에게 보내지 마세요.**

| 버튼 | 하는 일 |
|---|---|
| 방송용 순서 추첨 | 룰렛으로 순서 뽑기 (방송 화면에도 같이 나옴). 끝나면 **이 순서로 경매 시작** |
| 경매 시작 (Space) | 지금 선수의 시간이 흐르기 시작. 키보드 스페이스바로도 됨 |
| 일시정지 | 시간 멈춤. 다시 누르면(또는 Space) 이어서 |
| 지금 마감 | 남은 시간과 상관없이 바로 낙찰/유찰 |
| 다음 선수 | 결과 화면에서 바로 다음 선수로 |
| 다음 선수 자동 시작 | 켜 두면 결과 뒤 다음 선수가 자동으로 시작 |
| 결과 되돌리기 (N) | 가장 최근 결과부터 하나씩 취소하고 그 선수를 다시 경매 |
| 처음부터 다시 | 경매 결과를 모두 지우고 준비 단계로 (명단·링크는 그대로) |
| 소리 켜짐/꺼짐 | 진행자 화면 효과음 |
| 신청 명단 / 팀장 링크 / 운영자 콘솔 | 명단 보기, 링크 다시 보기, 콘솔로 가기 |

화면 보는 법
- 가운데: 지금 선수(사진, 티어, 주 요원, 각오), 현재 최고가와 팀, 남은 시간
- 아래: 팀 카드(남은 포인트, 최대 입찰 가능 금액, 빈자리와 필요한 티어)
- 팀 이름 옆 점: 그 팀장이 지금 접속해 있는지
- 오른쪽: 채팅(진행자와 팀장만), 진행 기록

### 되돌리기
- 잘못 마감했거나 입찰이 잘못 들어갔을 때 **결과 되돌리기**를 누릅니다.
- 가장 최근 결과부터 차례로 되돌리며(최근 30개), 포인트와 유찰 횟수도 돌아갑니다.
- 지금 선수에게 입찰이 들어와 있으면 먼저 **지금 마감**을 누른 뒤 되돌리세요.

### 팀장 쪽 화면 (안내용)
- 팀장 폰에는 **자기 팀 입찰 버튼만** 있습니다(+5, +10, 직접 입력).
- 입찰할 수 없으면 버튼이 꺼지고 이유가 나옵니다(포인트 부족, 빈자리 몫, 같은 티어 보유 등).
- 누가 먼저 눌렀는지는 서버가 도착 순서로 정합니다. 동시에 눌러도 한 명만 인정됩니다.
- 경매 중에는 폰 화면이 저절로 꺼지지 않습니다(지원하는 폰만). 아이폰은 화면을 한 번 터치해야 효과음이 납니다.

## 6. 결과

- 경매가 끝나면 팀이 한 팀씩 등장하고, 티어 점수 합계 1위 팀이 **우승 후보**로 강조됩니다.
- **결과 발표 다시 보기**: 연출 다시 재생
- **엑셀로 내려받기**: 팀 구성, 팀 요약, 팀에 못 들어간 선수 (팀·경매 티어·닉네임·디스코드 이름·티어·점수·포지션·주 요원·낙찰가)
- **이미지로 저장**: 결과를 PNG 한 장으로 받기 (디스코드에 올리기 좋음, 디스코드 이름은 안 나옴)
- 팀장 폰과 운영자 콘솔 **경매 결과** 탭에서도 받을 수 있습니다.

## 7. 경매 당일 체크리스트

전날
- [ ] 운영자 콘솔 위쪽이 **서버 정상**인지 확인
- [ ] 경매 선수 채우기 완료, 경매 티어 A~D 인원이 팀 수와 같은지
- [ ] 팀장 링크를 팀장들에게 보냄, 팀장들이 링크를 열어 "실시간 연결됨"이 뜨는지

30분 전
- [ ] OBS에 방송 화면 띄우고 소리 확인
- [ ] 진행자 화면 열기, 팀 이름 옆 점(접속)이 모두 켜졌는지
- [ ] 팀장들에게 "폰 소리 켜고, 화면 한 번 터치" 안내

진행
- [ ] 방송용 순서 추첨 → 이 순서로 경매 시작
- [ ] 경매 시작 (자동 시작을 켜면 편함)

끝
- [ ] 엑셀·이미지 저장, 디스코드에 결과 올리기

## 8. 문제가 생기면

- **팀장이 못 들어와요** → 그 팀 링크를 다시 보내세요(팀장 링크 버튼). 팀장 링크는 회차를 다시 채워도 바뀌지 않습니다.
- **팀장 폰이 "다시 연결 중…"이에요** → 인터넷이 돌아오면 저절로 최신 상태로 돌아옵니다. 오래가면 새로고침하세요. 경매는 서버에서 계속 진행됩니다.
- **잘못 낙찰됐어요** → 결과 되돌리기.
- **진행자 화면을 닫았어요** → 콘솔에서 **진행자 화면 열기**로 다시 여세요. 경매는 그대로 이어집니다.
- **경매 도중 누가 빠졌어요** → 경매를 끝낸 뒤 대기 인원 중 같은 티어로 바꾸는 것은 운영진이 따로 정리하세요(사이트의 결과는 그대로 둠).
- **소리가 두 번 들려요** → 같은 PC에서 진행자 화면과 방송 화면을 둘 다 켜고 OBS가 컴퓨터 소리까지 잡는 경우입니다. 진행자 화면 **소리 꺼짐**.
- **"이미 경매 선수로 올라간 사람이에요"** → 신청을 지우기 전에 경매 준비에서 그 사람의 "포함"을 끄고 다시 채우세요.

---

## 9. 회차 관리 (진행자·제작자만)

- **진행자 넘기기**: 경매 준비 탭 맨 위에서 다른 운영자를 고르고 **진행자 넘기기**.
- **선수 사진 지우기**: 일정 · 신청 마감 탭. 끝난 회차의 사진만 지워 저장 공간을 아낍니다(명단·결과는 그대로).
- **회차 지우기**: 일정 · 신청 마감 탭 맨 아래. 회차 이름을 똑같이 적어야 지워지고 되돌릴 수 없습니다. 지우기 전에 결과 엑셀을 받아 두세요.
